# Álgebra v2.1.0

PWA móvil para resolver sistemas de ecuaciones con resultados visuales y exactitud mediante fracciones.

## Versión

Se utiliza **Semantic Versioning**: `MAJOR.MINOR.PATCH`.

- **MAJOR**: cambios incompatibles o grandes rediseños.
- **MINOR**: funciones nuevas compatibles.
- **PATCH**: correcciones y mejoras menores.

La versión instalada se declara en `version.json`. La comprobación manual y automática compara esa versión con la versión de la aplicación.

## Novedades de v2.1.0

- Resultado exacto y decimal: `80/7 ≈ 11,428571`.
- Detección automática o selección manual del tamaño del sistema.
- Animación progresiva de los pasos.
- Vibración háptica opcional.
- Transiciones fade-in y fade-out.
- Diseño optimizado para móviles.
- Descarga de archivos para modo Offline con progreso, velocidad y tamaño por archivo.
- Comprobación manual y automática de actualizaciones.
