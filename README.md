# Álgebra

## Versión 2.4.0

PWA móvil para resolver problemas algebraicos paso a paso con presentación matemática visual.

### Tipos de problemas
- Sistemas de ecuaciones 2×2 y 3×3.
- Ecuaciones cuadráticas completas e incompletas.
- Soluciones reales, dobles y complejas.

### Métodos
**Sistemas:** Adición, Gauss-Jordan, Sustitución, Determinante y Matriz inversa.

**Cuadráticas:** detección automática, Factorización, Fórmula general y Extracción de raíz cuando corresponde.

### Funciones
- Detección automática y selección manual.
- Resultados con formato matemático visual, fracciones y decimales cuando aplica.
- Niveles Básico, Detallado y Completo.
- Historial local, copiar y compartir.
- Pantalla de inicio con versión y firma del desarrollador.
- Diseño móvil, navegación por pestañas e iconos SVG.
- Sistema de versiones MAJOR.MINOR.PATCH.

### Cambios en v2.4.0
